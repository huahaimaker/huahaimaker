## 我在意的不是“技术栈墙”

一个项目是否值得展示，我更看重这些证据：

- 用户能不能找到明确的安装或体验入口
- README 有没有说清楚能力、限制和安全边界
- Release、测试或真实运行截图能不能支撑项目状态
- 别人是否容易提交 Issue、参与改进或复用其中的能力

常用技术包括 `Swift / SwiftUI / AppKit`、`TypeScript / Obsidian`、`Python / Agent Orchestration`，以及 `WinUI / Tauri / Rust`。
