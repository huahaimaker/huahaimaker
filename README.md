## How I build

我做三件事：**把想法做出来，把产品交付出去，把有效的方法开源出来。**

- **真实可用** — 不止展示 Demo，也提供可运行的代码和清楚的使用入口。
- **可以验证** — 用 Release、测试、安装路径和真实运行结果支撑项目状态。
- **开放生长** — 写清能力与边界，让 Issue、Pull Request 和二次开发更容易发生。
